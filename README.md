# Phishing Email Analysis

## About the Project
This project focuses on analyzing a suspicious email and identifying common phishing indicators.

## Objective
To understand phishing attacks, recognize suspicious emails, and learn basic email threat analysis techniques.

## Tools Used
- Google Admin Toolbox
- MXToolbox
- Web Browser
- GitHub

## Phishing Indicators Identified
- Suspicious sender address
- Urgent and threatening language
- Suspicious verification link
- Generic greeting
- Social engineering techniques

## Analysis
A fictional phishing email was examined to identify common phishing characteristics. The email attempted to create urgency and encourage the receiver to click an unverified verification link.

## Key Learnings
- Understanding phishing attacks
- Identifying email spoofing
- Recognizing suspicious links
- Understanding email header analysis
- Learning safe email practices

## Conclusion
This project helped me understand how phishing emails work and how to identify suspicious email messages to improve cybersecurity awareness.
